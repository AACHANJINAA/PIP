## 1. 고정 타임스텝 동기화 시스템

### 🎯 핵심 설계 원칙

**30Hz 고정 타임스텝 (33.3ms)** 채택으로 서버 부하와 정확성의 최적 균형점 확보

```cpp
class NetworkPhysicsManager {
private:
    static constexpr float FIXED_TIMESTEP = 1.0f / 30.0f;  // 33.3ms
    static constexpr int MAX_SUBSTEPS = 2;                  // 최대 하위 스텝
    static constexpr int MAX_FRAME_BUFFER = 30;             // 1초분 프레임 저장
    
    float accumulator = 0.0f;
    uint32_t currentFrame = 0;
    
public:
    void Update(float realDeltaTime) {
        accumulator += realDeltaTime;
        
        // 고정 간격으로만 물리 업데이트 실행
        while(accumulator >= FIXED_TIMESTEP) {
            // 1. Jolt Physics 업데이트
            joltPhysics->Update(FIXED_TIMESTEP, MAX_SUBSTEPS);
            
            // 2. 상태 스냅샷 저장 (Rewind용)
            SaveStateSnapshot();
            
            // 3. 네트워크 동기화 데이터 준비
            PrepareNetworkSync();
            
            accumulator -= FIXED_TIMESTEP;
            currentFrame++;
        }
        
        // 보간을 위한 알파값 계산
        float interpolationAlpha = accumulator / FIXED_TIMESTEP;
        PrepareInterpolationData(interpolationAlpha);
    }
    
private:
    void SaveStateSnapshot() {
        PhysicsSnapshot snapshot;
        snapshot.frameID = currentFrame;
        snapshot.timestamp = GetCurrentTime();
        snapshot.joltState = joltPhysics->GetState();
        
        // 모든 엔티티 상태 저장
        for(auto& entity : activeEntities) {
            snapshot.entityStates.push_back(entity->GetPhysicsState());
        }
        
        stateHistory.Push(snapshot);
    }
};
```

### 🔧 타임스텝 동기화 장점

- **예측 가능한 시뮬레이션**: 매번 동일한 시간 간격으로 계산
- **네트워크 일관성**: 클라이언트-서버 간 동일한 물리 주기
- **디버깅 용이성**: 재현 가능한 물리 상태
- **성능 예측성**: CPU 사용량의 일정한 분산

## 2. NPC 동적 상태 관리 시스템

### 🚀 Dynamic Promotion 아키텍처

모든 NPC를 상시 Dynamic으로 처리하지 않고 **상호작용 단계별 최적화**

```cpp
class NPCPhysicsController {
public:
    enum class NPCPhysicsState {
        STATIC_IDLE,      // 완전 정지 - Trigger 충돌만 감지
        KINEMATIC_PATROL, // 경로 이동 - Collision Detection만
        DYNAMIC_COMBAT    // 완전 물리 시뮬레이션
    };

private:
    JPH::BodyID npcBodyID;
    NPCPhysicsState currentState = STATIC_IDLE;
    float combatStateTimer = 0.0f;
    float promotionRadius = 15.0f;  // 플레이어 15m 내 진입시 활성화
    
public:
    void UpdatePhysicsState(float deltaTime) {
        switch(currentState) {
            case STATIC_IDLE:
                UpdateIdleState();
                break;
            case KINEMATIC_PATROL:
                UpdatePatrolState(deltaTime);
                break;
            case DYNAMIC_COMBAT:
                UpdateCombatState(deltaTime);
                break;
        }
    }
    
    void PromoteToDynamic(const CombatEvent& event) {
        if(currentState != DYNAMIC_COMBAT) {
            // Jolt Body Type 즉시 변경
            auto* bodyInterface = joltPhysics->GetBodyInterface();
            bodyInterface->SetBodyType(npcBodyID, 
                JPH::EBodyType::RigidBody, 
                JPH::EActivation::Activate);
            
            // 물리적 속성 활성화
            bodyInterface->SetGravityFactor(npcBodyID, 1.0f);
            bodyInterface->SetMotionType(npcBodyID, JPH::EMotionType::Dynamic);
            
            currentState = DYNAMIC_COMBAT;
            combatStateTimer = 5.0f; // 5초간 전투 상태 유지
            
            // 이벤트 로깅
            LogStateTransition("NPC_PROMOTED_TO_DYNAMIC", event);
        }
    }
    
    void DemoteToKinematic() {
        if(currentState == DYNAMIC_COMBAT) {
            auto* bodyInterface = joltPhysics->GetBodyInterface();
            bodyInterface->SetBodyType(npcBodyID, 
                JPH::EBodyType::Kinematic, 
                JPH::EActivation::DontActivate);
            
            currentState = KINEMATIC_PATROL;
            
            LogStateTransition("NPC_DEMOTED_TO_KINEMATIC");
        }
    }

private:
    void UpdateIdleState() {
        // Trigger 충돌만 확인 (플레이어 접근 감지)
        if(IsPlayerNearby(promotionRadius)) {
            PromoteToKinematic();
        }
    }
    
    void UpdatePatrolState(float deltaTime) {
        // 간단한 레이캐스트로 지형 추적
        ProcessGroundRaycast();
        
        // 순찰 경로 이동 (Kinematic 이동)
        MoveAlongPatrolPath(deltaTime);
        
        // 전투 상황 감지
        if(IsInCombatSituation()) {
            PromoteToDynamic(CombatEvent{});
        }
    }
    
    void UpdateCombatState(float deltaTime) {
        combatStateTimer -= deltaTime;
        
        // 전투 종료 조건 체크
        if(combatStateTimer <= 0.0f && !IsInActiveCombat()) {
            DemoteToKinematic();
        }
    }
    
    void ProcessGroundRaycast() {
        // 하향 레이캐스트로 지형 높이 보정
        JPH::Vec3 rayStart = GetPosition() + JPH::Vec3(0, 0.5f, 0);
        JPH::Vec3 rayEnd = rayStart + JPH::Vec3(0, -2.0f, 0);
        
        JPH::RRayCast ray(rayStart, rayEnd - rayStart);
        JPH::RayCastResult result;
        
        if(joltPhysics->GetNarrowPhaseQuery().CastRay(ray, result)) {
            // 지면 높이로 Y 위치 보정
            JPH::Vec3 newPos = GetPosition();
            newPos.SetY(result.GetHitPoint().GetY());
            SetPosition(newPos);
        }
    }
};
```

| 상태 | CPU 사용률 | 메모리 | 충돌 정밀도 | 사용 시나리오 |
|------|------------|--------|-------------|---------------|
| **STATIC_IDLE** | 5% | 최소 | Trigger만 | 대기/휴식 |

| **DYNAMIC_COMBAT** | 100% | 최대 | 완전 정밀 | 전투 |

## 3. 서버 권위적 Rewind 시스템

### 🕰️ 과거 시점 복원 및 검증 시스템

정교한 히트 판정을 위한 **Time-Travel 기반 검증**

```cpp
struct PhysicsSnapshot {
    uint32_t frameID;
    double timestamp;
    std::vector<EntityState> entityStates;
    JPH::PhysicsSystemSnapshot joltState;  // Jolt 내부 상태 전체
    
    // 압축을 위한 델타 인코딩
    bool isDeltaEncoded = false;
    uint32_t baseFrameID = 0;
};

class ServerRewindSystem {
private:
    RingBuffer<PhysicsSnapshot, 30> stateHistory;    // 1초분 (30프레임)
    std::unordered_map<PlayerID, float> playerLatencies;
    
public:
    bool ValidateAttackHit(const AttackEvent& attack) {
        // 1. 클라이언트 지연시간 보상 계산
        float clientLatency = GetPlayerLatency(attack.attackerID);
        double compensatedTime = attack.timestamp - clientLatency;
        
        // 2. 해당 시점의 스냅샷 찾기
        auto snapshot = FindSnapshotByTimestamp(compensatedTime);
        if(!snapshot) {
            LogError("Snapshot not found for timestamp", compensatedTime);
            return false;
        }
        
        // 3. 물리 세계를 과거 시점으로 복원
        PhysicsWorldState currentState = BackupCurrentState();
        RestorePhysicsState(*snapshot);
        
        // 4. 해당 시점에서 충돌 재검증
        bool isValidHit = PerformHitValidation(attack);
        
        // 5. 현재 시점으로 복구
        RestorePhysicsState(currentState);
        
        // 6. 검증 결과 로깅
        LogAttackValidation(attack, isValidHit, compensatedTime);
        
        return isValidHit;
    }
    
private:
    bool PerformHitValidation(const AttackEvent& attack) {
        // 공격자 위치 및 방향 확인
        auto attackerState = GetEntityState(attack.attackerID);
        auto targetState = GetEntityState(attack.targetID);
        
        if(!attackerState || !targetState) return false;
        
        // Jolt Shape Cast를 이용한 정밀 충돌 검사
        JPH::ShapeCastSettings castSettings;
        castSettings.mBackFaceMode = JPH::EBackFaceMode::IgnoreBackFaces;
        
        // 공격 범위를 Shape으로 정의
        auto attackShape = CreateAttackShape(attack.weaponType, attack.attackRange);
        
        JPH::ShapeCast shapeCast(
            attackShape, 
            JPH::Vec3::sReplicate(1.0f),  // 스케일
            attackerState->transform,      // 시작 위치
            attack.attackDirection        // 공격 방향
        );
        
        JPH::ShapeCastResult result;
        bool hit = joltPhysics->GetNarrowPhaseQuery().CastShape(
            shapeCast, castSettings, result, 
            JPH::BroadPhaseLayerFilter(), 
            JPH::ObjectLayerFilter()
        );
        
        if(hit && result.mBodyID2 == targetState->bodyID) {
            // 추가 검증: 공격 각도, 거리, 방어 상태 등
            return ValidateHitDetails(attack, result, *targetState);
        }
        
        return false;
    }
    
    bool ValidateHitDetails(const AttackEvent& attack, 
                           const JPH::ShapeCastResult& result,
                           const EntityState& target) {
        // 1. 공격 거리 검증
        float hitDistance = result.mFraction * attack.attackRange;
        if(hitDistance > attack.maxValidRange) return false;
        
        // 2. 공격 각도 검증 (백스탭 등)
        JPH::Vec3 attackDirection = result.mContactPointOn2 - result.mContactPointOn1;
        float attackAngle = attackDirection.Dot(target.forwardDirection);
        
        if(attack.requiresFrontalHit && attackAngle < 0.5f) return false;
        
        // 3. 방어 상태 검증
        if(target.isBlocking) {
            JPH::Vec3 blockDirection = target.blockDirection;
            float blockAngle = attackDirection.Dot(blockDirection);
            
            if(blockAngle > 0.7f) { // 70% 이상 정면 블록
                return false; // 블록 성공
            }
        }
        
        // 4. 무적 프레임 검증
        if(target.isInvulnerable || target.iframeRemaining > 0) {
            return false;
        }
        
        return true;
    }
    
    void RestorePhysicsState(const PhysicsSnapshot& snapshot) {
        // Jolt 물리 시스템 상태 복원
        joltPhysics->RestoreSnapshot(snapshot.joltState);
        
        // 개별 엔티티 상태 복원
        for(const auto& entityState : snapshot.entityStates) {
            auto entity = GetEntity(entityState.entityID);
            if(entity) {
                entity->RestorePhysicsState(entityState);
            }
        }
    }
};
```

### 🎯 Rewind 시스템의 핵심 기능

1. **지연 보상 (Lag Compensation)**: 클라이언트 네트워크 지연만큼 과거로 되돌림
2. **정밀 충돌 재검증**: Jolt Shape Cast로 정확한 히트박스 검사  
3. **상태 일관성 보장**: 복원 후 반드시 현재 상태로 되돌림
4. **상세 검증 로직**: 거리, 각도, 방어, 무적 프레임 모두 고려

### 🌍 공간 기반 관심 영역 (Spatial AOI) 관리

```cpp
class SpatialAOIManager {
private:
    static constexpr float GRID_SIZE = 50.0f;    // 50m x 50m 그리드
    static constexpr float COMBAT_RADIUS = 25.0f; // 전투 활성화 반경
    
    struct SpatialGrid {
        std::vector<EntityID> staticEntities;    // 정적 오브젝트
        std::vector<EntityID> kinematicNPCs;     // 순찰 NPC
        std::vector<EntityID> dynamicEntities;   // 전투 상태 엔티티
        bool hasActiveCombat = false;
    };
    
    std::unordered_map<GridCoord, SpatialGrid> spatialGrids;
    
public:
    void UpdateAOI(uint32_t frameID) {
        // AOI는 물리 업데이트보다 낮은 빈도로 갱신 (10Hz)
        if(frameID % 3 != 0) return;
        
        for(auto& player : activePlayers) {
            UpdatePlayerInfluenceZone(player);
        }
        
        OptimizePhysicsStates();
    }
    
private:
    void UpdatePlayerInfluenceZone(const Player& player) {
        GridCoord playerGrid = WorldToGrid(player.position);
        
        // 플레이어 주변 3x3 그리드 영역 활성화
        for(int dx = -1; dx <= 1; dx++) {
            for(int dz = -1; dz <= 1; dz++) {
                GridCoord targetGrid = {playerGrid.x + dx, playerGrid.z + dz};
                ActivateGridForCombat(targetGrid);
            }
        }
    }
    
    void ActivateGridForCombat(const GridCoord& grid) {
        auto& spatialGrid = spatialGrids[grid];
        
        if(!spatialGrid.hasActiveCombat) {
            // 해당 그리드의 NPC들을 Kinematic으로 승격
            for(auto npcID : spatialGrid.staticEntities) {
                auto npc = GetNPC(npcID);
                if(npc && npc->GetState() == NPCPhysicsState::STATIC_IDLE) {
                    npc->PromoteToKinematic();
                }
            }
            
            spatialGrid.hasActiveCombat = true;
        }
    }
};
```

### 📈 예측적 상태 버퍼링

```cpp
class PredictiveStateManager {
private:
    struct PlayerLatencyProfile {
        float averageLatency;
        float latencyVariance;
        int recommendedBufferSize;
        uint32_t lastUpdateFrame;
    };
    
    std::unordered_map<PlayerID, PlayerLatencyProfile> latencyProfiles;
    
public:
    void AdaptBufferSize(PlayerID playerID) {
        auto& profile = latencyProfiles[playerID];
        
        // 지연시간 기반 버퍼 크기 동적 계산
        float maxLatency = profile.averageLatency + (profile.latencyVariance * 2.0f);
        int requiredFrames = (int)(maxLatency / FIXED_TIMESTEP) + 5; // 여유분
        
        if(requiredFrames > profile.recommendedBufferSize) {
            profile.recommendedBufferSize = requiredFrames;
            ExpandStateBuffer(playerID, requiredFrames);
            
            LogBufferResize(playerID, requiredFrames, maxLatency);
        }
    }
    
    void UpdateLatencyMeasurement(PlayerID playerID, float currentLatency) {
        auto& profile = latencyProfiles[playerID];
        
        // 지수 이동 평균으로 지연시간 추적
        profile.averageLatency = profile.averageLatency * 0.9f + currentLatency * 0.1f;
        
        // 분산 계산
        float deviation = currentLatency - profile.averageLatency;
        profile.latencyVariance = profile.latencyVariance * 0.9f + (deviation * deviation) * 0.1f;
        
        profile.lastUpdateFrame = GetCurrentFrame();
    }
};
```

### 🧮 결정론적 물리 초기화

```cpp
class DeterministicPhysicsSetup {
public:
    void InitializeJoltPhysics() {
        // 결정론적 설정으로 초기화
        JPH::PhysicsSystemSettings settings;
        
        // 고정된 스레드 수 (결정론 보장)
        settings.mMaxBodies = 65536;
        settings.mMaxBodyPairs = 65536;
        settings.mMaxContactConstraints = 10240;
        
        // 결정론적 브로드페이즈 설정
        settings.mBroadPhaseType = JPH::EBroadPhaseType::BroadPhase2D;
        settings.mObjectLayerPairFilter = &objectLayerPairFilter;
        
        // 고정된 시뮬레이션 파라미터
        joltPhysics = new JPH::PhysicsSystem();
        joltPhysics->Init(settings);
        
        // 중력 설정 (모든 플랫폼에서 동일)
        joltPhysics->SetGravity(JPH::Vec3(0.0f, -9.81f, 0.0f));
        
        // 결정론적 솔버 설정
        joltPhysics->SetPhysicsSettings(CreateDeterministicPhysicsSettings());
    }
    
private:
    JPH::PhysicsSettings CreateDeterministicPhysicsSettings() {
        JPH::PhysicsSettings settings;
        
        // 고정된 반복 횟수 (결정론 보장)
        settings.mNumVelocitySteps = 10;
        settings.mNumPositionSteps = 2;
        
        // 고정된 허용 오차
        settings.mBaumgarte = 0.2f;
        settings.mSpeculativeContactDistance = 0.02f;
        settings.mPenetrationSlop = 0.01f;
        
        // 결정론적 충돌 감지
        settings.mLinearCastThreshold = 0.75f;
        settings.mLinearCastMaxPenetration = 0.25f;
        
        return settings;
    }
};
```
